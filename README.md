# Urban Sounds Shoes

Tienda frontend adaptable a móviles, creada con HTML, CSS y JavaScript puro.

## Cómo abrir
1. Descarga y descomprime el proyecto.
2. Abre `index.html` en tu navegador. También puedes usar la extensión **Live Server** de VS Code.
3. Edita los productos, precios, correo de contacto y textos en `script.js` e `index.html`.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `urban-sounds-shoes`.
2. Sube `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda y espera a que GitHub Pages publique el sitio.

## Funciones incluidas
- Catálogo filtrable de cuatro modelos conceptuales.
- Carrito con cantidades, eliminación y subtotal, guardado en `localStorage`.
- Perfiles de cliente, comercio/mayorista y administrador (solo selección demostrativa).
- Formulario de checkout con métodos de pago y opciones de entrega.
- Solicitud de pedidos especiales y consultas mayoristas mediante enlace `mailto`.
- Diseño responsive.

## Importante antes de vender de verdad
Este proyecto es una **demo frontend**. No procesa pagos, no autentica usuarios de forma segura, no guarda pedidos en una base de datos y no gestiona inventario ni envíos reales. Para operar comercialmente debes conectar un backend, autenticación, base de datos y una pasarela de pago segura. Nunca recolectes números de tarjeta directamente en esta página.

Los nombres de artistas se usan únicamente para describir inspiración estética. La tienda no debe presentarse como oficial ni afiliada con Travis Scott, Drake, Metro Boomin o Bad Bunny. No uses logotipos, fotografías ni diseños protegidos sin autorización.
